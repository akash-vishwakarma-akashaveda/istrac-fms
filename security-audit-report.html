📦 Backend Dependencies Audit (D:\istrac-fms\backend)

multer: Denial of Service & Descriptor Leak on Aborted Uploads
HIGH multer@2.2.0
Advisory IDGHSA-qfvm-cv95-jqjf, GHSA-535w-7cp7-47q4
CWE ReferenceCWE-400 (Resource Exhaustion), CWE-459
CVSS v3 Score7.5 (High)
Affected Range<= 2.2.0
When an HTTP file upload multipart stream is abruptly terminated or an oversized array index is provided in field names, temporary file descriptors may leak, causing memory or resource exhaustion under continuous aborted stream floods.
💡 Remediation: Update to multer@^2.3.0 or higher via npm install multer@latest. In air-gapped intranet mode, reverse proxy request limits in Apache (LimitRequestBody 104857600) actively mitigate oversized payloads.
nodemailer: Address Parser Quadratic Time Complexity & Domain Validation
HIGH nodemailer@9.0.5
Advisory IDGHSA-2x7j-588g-ccc2, GHSA-8m3c-c648-2xjj
CWE ReferenceCWE-400, CWE-407 (Algorithmic Complexity)
CVSS v3 Score7.5 (High)
Affected Range< 9.1.0
Quadratic time complexity in address parsing allows potential denial of service via crafted email headers. Also, content resolution on legacy signatures can bypass access controls.
💡 Remediation: Update to nodemailer@^9.1.0 via npm install nodemailer@latest. Note: In this deployment, external SMTP is suppressed and OTPs are routed to database/terminal logs, eliminating attack surface.
mysql2 (via Prisma): Auth Plugin Downgrade & Inflate DoS
HIGH mysql2@3.23.0 (Prisma Transitive)
Advisory IDGHSA-3f6p-5ww8-9rcr, GHSA-rgwj-5xj2-c3m3
CWE ReferenceCWE-522 (Credential Leak), CWE-409
CVSS v3 Score5.9 (Moderate / High Auth)
Affected Range<= 3.23.0
Auth plugin downgrade may attempt clear-password if requested by an adversarial rogue MySQL server. Unbounded zlib inflate can cause decompression-bomb DoS if packet compression is enabled.
💡 Remediation: Prisma bundles this driver. In local air-gapped RHEL deployment, the backend connects strictly to local 127.0.0.1:3306 with native TLS/socket trust, mitigating man-in-the-middle rogue server injection.
